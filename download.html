Télécharger PakDok (version bêta)

Merci de télécharger PakDok. Cette version est fournie telle quelle : pensez à sauvegarder vos documents régulièrement.

Android (APK)

Téléchargez et installez manuellement l'APK sur votre téléphone Android. Pour installer, suivez ces étapes :

  1. Ouvrez l’application Paramètres de votre téléphone.
  2. Recherchez “Installer des applications inconnues” ou “Sources inconnues”.
  3. Sélectionnez le navigateur ou gestionnaire de fichiers utilisé pour télécharger l’APK.
  4. Activez l’option Autoriser à partir de cette source.
  5. Téléchargez l’APK en cliquant ci-dessous.
  6. Ouvrez le fichier téléchargé pour lancer l’installation.
  7. Une fois installé, ouvrez PakDok depuis votre téléphone.
